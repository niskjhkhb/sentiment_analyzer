# Sentiment Analysis App

An interactive **sentiment analysis web application** built with Python and Streamlit for analyzing the sentiment of user-provided text through a simple and intuitive interface.

## Features

-  Analyze text sentiment
-  Apply Natural Language Processing (NLP) for sentiment classification
-  Interactive Streamlit web interface
-  Lightweight and easy to run locally
-  SQLite database integration

## Tech Stack

- **Python**
- **Streamlit**
- **Natural Language Processing (NLP)**
- **SQLite**

## Project Structure

```text
sentiment-analysis-app/
│
├── app.py                # Streamlit application
├── sentiment.db          # SQLite database
├── requirements.txt      # Python dependencies
└── .streamlit/           # Streamlit configuration
```

## Installation

### 1. Clone the repository

```bash git clone [https://github.com/nisrineamroug/sentiment-analysis-app.git](https://github.com/nisrineamroug/sentiment-analysis-app.git) cd sentiment-analysis-app ```

### 2. Install dependencies

```bash pip install -r requirements.txt ```

### 3. Run the application

```bash streamlit run app.py ```

The application will open automatically in your browser.

## Usage

## Launch the Streamlit application.

## Enter or provide the text you want to analyze. ## Run the sentiment analysis. ## View the predicted sentiment through the application interface.
